# Serralheria Ecommerce

Ecommerce de serralheria (portões, grades, corrimãos, estruturas metálicas). Stack: **Medusa** (backend/admin) + **Next.js** (storefront).

## Para desenvolvedores

- **Como rodar:** `docker compose up -d` e `npm run dev` (ver [CHECKLIST.md](./CHECKLIST.md)).
- **Estado do projeto e próximos passos:** [CHECKLIST.md](./CHECKLIST.md) e [CONTINUE_PROMPT.md](./CONTINUE_PROMPT.md).

## Para IA continuando o projeto

**Leia primeiro:** [AGENTS.md](./AGENTS.md) — explica como trabalhar, onde está o checklist e como atualizá-lo ao concluir tarefas. Depois leia [CHECKLIST.md](./CHECKLIST.md) e [CONTINUE_PROMPT.md](./CONTINUE_PROMPT.md) para saber onde estamos e o que fazer em seguida.

O checklist é atualizado no repositório (marcar `[x]` nos itens concluídos); ao dar commit e push, o estado fica no GitHub.

## Marca (logo e fundo)

Arquivos usados pelo tema ficam em:
- storefront/public/brand/logo.png
- storefront/public/brand/bg-steel.png

1) Substitua os arquivos mantendo o mesmo nome.
2) Rode git add -A / git commit -m "brand: update" / git push.
